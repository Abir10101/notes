defination: Distributed DBMS is a database software system that manages a database spread across multiple physical locations while making it appear as single logical database to end user. In this, data is not stored in single machine but is distributed over a network of computers.

Types of DDBMS:
Classification based on software similarity across different sites:
- Homogeneous DDBMS: In this all sites use the same dbms software (MySQL or Oracle).
- Heterogeneous DDBMS: In this all sites use different dbms software.
